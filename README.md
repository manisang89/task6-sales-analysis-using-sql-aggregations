# Sales Analysis Using SQL (Aggregations)

This task involves analyzing sales trends using SQL aggregate functions such as `SUM`, `COUNT`, `AVG`, `MIN`, `MAX` on an online sales dataset.

## Files Included

- **Online Sales Data.csv** – Dataset used for analysis
- **sales_data_table.sql** – SQL script to create the table and import the CSV into PostgreSQL
- **queries.sql** – SQL queries using aggregation functions to analyze trends (revenue, transactions, etc.)
- **outputs.xlsx** – Excel file containing the result tables for each query

## Tool used

- **PostgreSQL**
